## 1. สรุปสั้น

| เรื่อง | v35 “Calm” (ก่อน) | v41 “Google Material” (หลัง) |
|---|---|---|
| พื้นหลังหน้า | `#fafafa` แบน | `#f8f9fa` (Google grey 50) + การ์ดขาวลอยขึ้นมา |
| สีเน้น | หนึ่งสี (น้ำเงิน `#0f5ef5`) | หนึ่งสี (Google blue `#1a73e8`) **+ tint 10% ของสีนั้น** ในชิป/ปุ่มเลือก |
| เงา | ไม่มี ยกเว้นของลอย (ชีต/ท็อสต์) | **Material elevation** 1dp การ์ด / 2dp hover / 3–4dp ของลอย |
| เมนู | ชิปขอบบาง active = พื้นเทา | **แท็บกลม** active = พิลน้ำเงินทึบ (desktop) / พิล tint (มือถือ) |
| ชิปตัวกรอง | มุม 8px, active = พื้นเทา + เส้นเข้ม | **พิล**, active = tint 10% + ขอบน้ำเงิน + ตัวอักษรน้ำเงิน |
| ปุ่ม | มุม 8px, primary ทึบ | **พิล**, primary ทึบ, secondary = outlined ตัวอักษรน้ำเงิน |
| ช่องกรอก | ขอบ 1px มุม 8px | **outlined 4px** + โฟกัสเป็นเส้นน้ำเงิน 2px (สไตล์ Google) |
| ท็อสต์ | การ์ดขาว | **snackbar ดำ** ตัวอักษรขาว (โหมดมืดกลับด้าน) |
| ฟอนต์ | IBM Plex Sans Thai + Plex Mono | **Google Sans** (ไทย/ละติน) + **Google Sans Code** (ตัวเลข) |
| ตัวเลข | tabular | tabular + Google Sans Code ในใบเสร็จ |

ของที่ **ไม่** เปลี่ยน เพราะเป็นข้อกำหนดของโปรเจกต์และยังใช้ได้กับสไตล์ Google:
เมนู/โครงข้อมูลเดิมทั้งหมด · หนึ่งปุ่มหลักต่อหน้า · เขียว/แดงเฉพาะจำนวนเงิน ·
ตัวอักษรขั้นต่ำ 12px · ระยะบรรทัดไทย ≥ 1.4 · เป้ากด ≥ 44px · ปี พ.ศ. ·
ไม่มีข้อความอังกฤษล้วนบนจอไทย · ไม่มี `transition: all` · easing เดียว (`--ease`).

## 5. จุดที่ควรตรวจด้วยตา (screenshots ทำไม่ได้ใน environment นี้)

เครื่องใน sandbox ไม่มีเบราว์เซอร์ headless (`libnss3` หาย, ติดตั้งไม่ได้) จึงตรวจด้วย
โค้ด/เทสต์เท่านั้น หน้าจอที่ควรเปิดดูเอง:

1. **แถบบน desktop** — โลโก้วงกลม 40px, แท็บกลม, แท็บ active เป็นพิลน้ำเงิน, ความสูงรวม 113px
   (แถวแบรนด์ 64 + แถวแท็บ 48) และหน้าที่มี `.page-head` ไม่ชนแถบ
2. **แถบล่างมือถือ** — dock พิลสูง 48px, ไอเท็ม active เป็นพิล tint, ไม่มีขีด `::before`
3. **แดชบอร์ด** — การ์ดขาวเงา 1dp, KPI 3 ช่องในแถวเดียว, การ์ด widget มีแถบสี 3px หน้าหัวข้อ
4. **ค่าใช้จ่าย/เคลียร์บิล** — ชิปตัวกรองเป็นพิล, ปุ่มเลือกวิธีจ่าย active เป็น tint 10% + ขอบน้ำเงิน,
   ใบเสร็จกระดาษขาว + ตัวเลข Google Sans Code
5. **โหมดมืด** — ปุ่มหลัก/แท็บ active/FAB ต้องเป็นน้ำเงินอ่อน `#63a0ef` กับ **หมึกเข้ม**
   (ถ้าเห็นตัวอักษรขาวบนน้ำเงินอ่อน = ถอยหลัง ให้กลับไปดู §3)
6. **ฟอนต์ไทย** — Google Sans มี subset ไทยจริง; ตัวเลขในปฏิทิน/ใบเสร็จควรเป็น tabular
   และ Google Sans Code ใช้เฉพาะอักษรละติน/ตัวเลข (ไม่มีไทย — ตั้งใจ)

พรีวิวแบบเต็มหน้า (CSS + ฟอนต์ + ไอคอนครบ): `tools/preview/out/<route>.full.html`
(`dashboard`, `trips`, `expenses`, `settlement`, `settings`) และ `*.full-dark.html`
